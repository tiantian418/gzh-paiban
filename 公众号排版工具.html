推荐流程（每篇 5 分钟）

  1. 顶栏左侧点 夜读 / 热搜 / 科普 / 带货 / 财税 选栏目：写过就接上那篇，没写过就自动铺好该栏目的整篇架构
  2. 把 ## 01 / 02 / 03 下的占位文字换成正文（引言、正文、结尾）
  3. 点右上角 复制到公众号 → 后台新建图文 → Ctrl+V

① 写好内容

左边写 Markdown，右边实时预览，草稿自动存浏览器本地。图片有三条路：Ctrl+V 粘贴、 点格式工具条里的 ＋ 图片 选文件（可多选）、或者直接把图拖进编辑区 —— 后两条会自动压成 1080px 宽的 JPEG 再插到光标处，一张照片两百来 KB，草稿存得下十几张。 同一排右边的 ＋ 表格 插一个 3×3 的空表，比较缴费比例、税率档位这种地方比手敲竖线快。
夜读 / 热搜 / 科普 / 带货 / 财税各存一份草稿（正文 + 标题样式 + 引用样式 + 行距 + 字号 + 预览宽度一起记）： 写到一半切去热搜，热搜那边还是上次的热搜稿；切回夜读，夜读这边原样回来，五边互不覆盖。
栏目在顶栏左侧，不用进任何菜单：点「热搜」就接上上次那篇热搜稿，点「夜读」就接回夜读稿。 鼠标悬停在栏目上能看到它上次存稿的时间。还没写过的栏目会自动铺好它的整篇架构 （引言 → 01/02/03 → 写到最后 → 点赞 → 关注卡），当前这篇已经先存回它自己的栏目，不会丢。
五栏目版式完全一样（引言 → 01/02/03 → 写到最后 → 点赞 → 关注卡， 组件尺寸也是同一套），差别只在配色 —— 所以五个栏目写起来手感一致，切过去版面不动、只有颜色换。 唯一多出来的是带货：它在 03 后面自带一张商品卡 + 购买引导，其余结构一样。
关工具再打开，也回到上次停的那个栏目。
打开一定有东西看：回到上次停的那个栏目 —— 那个栏目写过，就把那篇原样摆回来； 没写过，就铺好它自己的整篇架构。四个栏目各自都有一套完整架构，所以不会出现空白页。
「插入示例」只是给你看版式，不会被记成存稿；骨架也不算存稿—— 不管是今天铺的、还是老版本留下来的老骨架，只要里面没有你写的正文，切栏目时都会照常铺最新架构。
想推倒重来点「重铺架构」（在编辑器上方、「插入示例」右边）：把当前栏目按最新版重新铺一遍。 栏目里有正文时会先问一句，确认了才动。
老稿会自动跟上新文案：点赞口径统一成「赞 / 推荐」、关注卡里的时间行去掉、老式 ## 01 第一个小标题 补成管道式（带英文小字字段）—— 只认原样没改过的默认文案， 你自己改过的句子一个字不动。
基础格式有按钮：选中文字，点编辑器上方的 B / I / U / S / 高亮 / </> / 链接 直接套上，再点一下取消； 同一排右边还有 ＋ 图片 / ＋ 表格 / — 分割线 三个插入按钮，都是往正文里放东西。 快捷键 Ctrl+B 加粗、Ctrl+I 斜体、Ctrl+U 下划线。 手写 Markdown 也照旧：**粗体**、*斜体*、++下划线++、~~删除线~~、==高亮==、`行内代码`。

② 选主题 / 标题样式

顶部主题卡片共五张，对应五个栏目：夜读深蓝（米色 + 深蓝 + 金）、 落日橘光（暖橘 + 砖红）、墨绿科普（浅绿 + 墨绿 + 黄底线）、 带货玫金（玫红 + 酒红 + 金，好物推荐 / 团购文那一挂）、 财税赭石（赭石 + 深砖 + 米黄，旧账簿的调子，算账 / 报税 / 社保这类实用文用）。 五张卡片换的是颜色，版式是同一套 —— 想换的只是配色时点卡片，想换栏目时点顶栏左侧。
主题栏右侧有标题（竖线 / 序号 / 章节条 / 色块 / 居中 / 下划线）、 引用（竖线 / 卡片 / 重点句）、行距（常规 / 紧凑）、 正文字号（14–20px，滑杆旁边就是具体数字）四个选择器，可自由组合。
标题样式各栏目自带一档（2026-09-24 起）：夜读 → 章节条（刊物感）、 热搜 → 序号（清单感、快节奏，热点文的「第一点、第二点」正好用得上）、 科普 → 竖线（线条化、不抢戏，配 15px 密排正文最舒服）、 带货 → 色块（整条实色底，促销味、在货架流里最抓眼）、 财税 → 下划线（深砖字 + 赭石横线，像账本上的一道线，看着就像在算账）。 五个栏目因此各有一枚标题指纹 —— 读者滑到一篇，不看文字也能认出是哪个号。 铺架构 / 切栏目 / 重铺架构时会自动套上本栏目的那一档，想换随时在顶栏点， 换了会跟着这篇的草稿一起记住；分栏默认档之前写的老稿也会自动升级一次 （只换标题的排法、正文一个字不动，见 ⑤）。
骨架铺出来的标题是 ## 01｜小标题｜SECTION ONE 这种三字段写法， 把中文和英文都替换成自己的就行（英文那行只在章节条档显示，见下）。
顶栏「标题」这六个档位永远说了算（2026-09-24 修）：管道写法只是「字段格式」， 不代表一定要用章节条 —— 选「竖线 / 序号 / 色块 / 居中 / 下划线」时， 管道式标题会自动降级成单行式「数字 + 标题」，不用去改正文里的竖线。 切到「序号」数字会渲染成色块；不要数字就写 ## 小标题。
关于那行英文小字：它是章节条这个样式的一部分（大数字下面配一行疏排小字，左右才平衡）， 建议留着。第三段不写也会自动补 PART（结语位补 LAST）， 所以「带英文」是章节条的默认状态；不想要英文就把顶栏「标题」切到「竖线」或「序号」， 数字旁边就没有小字（那行小字没有别的地方可放，切档即隐去）。 正文里那些英文不用删——切回「章节条」它们就回来； 老稿里空格式的默认小标题会被自动补成管道式（带英文），想撤掉随时切档。

②′ 四个栏目的组件尺寸是同一套（照科普那套来）

科普那张卡取自一篇样式很好的科普号文章：墨绿 #059669 作主色、 近黑作标题、雾灰作正文。正文强调走「浅绿下划线」而不是底色块 —— 与另三个栏目同一手法、只是颜色不同。
它的组件尺寸现在是四个栏目的统一基准：
· 刊头 —— 白底 + 1px 浅色描边 + 8px 圆角 + 内边距 14/16，一句主句带 3px 底线
· 点赞 —— 上下 1px 细线夹住的居中单句，14px
· 关注卡 —— 8px 圆角 + 内边距 24/20/22，白底二维码框 160×140
· 重点句 —— 14px 圆角 + 内边距 22/20，17px 主句居中
夜读 / 热搜 / 带货的同名卡已逐项按这套尺寸重做，所以切栏目时版面尺寸一点不动， 只有颜色换成那个栏目的。每个栏目都是这四张卡（刊头 / 点赞 / 关注 / 重点句），一一对应， 不会有哪张卡在某个栏目里找不到替代。组件在抽屉里按栏目分组，组内顺序也一致： 刊头 → 点赞 → 关注 → 重点句（带货那一组后面还多了商品卡 / 购买引导两张）。
重点句卡片四个栏目互为同构版 —— 正文里已有别的栏目版时，点新的一张直接原地换皮，卡里那句保留； 「引用」选「卡片」档时边框用本栏目的引用专用色 —— 和「竖线」档同一条色 （夜读钢蓝 / 热搜琥珀 / 科普深青绿 / 带货莓紫，各自只是本栏目色系里另取的一档， 与标题色、主色都不重），有意与重点句卡片、刊头的浅描边在颜色上分开： 引用的三档共用这条色，其它模块都不用它，看到这条色就知道「这段是引来的话」。
正文轮廓：科普 15px 正文、1.9 行距（点这张卡时字号自动按这套走，顶栏「正文字号」滑杆仍可整体加减）。
四个栏目的行距、段间距、正文缩进完全一致（都是常规档、都不缩进），所以四个栏目切换时 版面节奏不变，只有颜色在换。想在某一篇里收紧行距，随时可在顶栏「行距」切「紧凑」——那只影响当前这篇。

③ 组件语法

① 小标题：## 01｜第一个小标题｜SECTION ONE → 顶栏「标题」选章节条时是四件套 （大数字 / 数字下英文小字 / 加粗标题 / 标题下英文小字，四个栏目默认样式，英文小字可省略）； 选其它档时同一行文字自动变成「01 第一个小标题」的单行式，不用改正文。
② 下划线强调：正文里 ==这几个字== → 下划线 + 加粗（墨绿栏目是浅绿下划线，不用底色块）。
③ 引用：单独一行 > 一句值得拎出来的话 → 左侧竖线 + 浅底（可在顶栏「引用」切成卡片或重点句）。
④ 卡片：点赞 / 关注卡用抽屉里的片段，铺架构时已放好位置，替换文字即可。 刊头卡不再自动铺（正文顶上已有大标题，再压一张定调卡是把标题说两遍）—— 想要就自己去抽屉里插，卡片还在，五个栏目的都有。
⑤ 分割线：点工具条上的 — 分割线，光标处就插一条；也可以手打 ---（*** / ___ 同样认），必须单独一行，否则会粘到上一段的行尾。 点开的小面板里有 五档线型（渐变 / 细线 / 短线 / 虚线 / 双线）， 左边那条预览用的就是当前栏目的颜色，选之前先看到长什么样。 线型整篇统一 —— 跟标题档、引用档一样属于「这篇的调子」， 一篇里出现三种线读者只会觉得乱；颜色则自动跟栏目走，不用管。
分隔符 全角｜半角 | 都认，## 01 | 标题、## 1 | 标题（一位数自动补成 01）都行。
卡片跟着主题走：切栏目时正文里的刊头 / 点赞 / 关注卡自动换成对应栏目版 （自己改过卡里文字的不会被动）。

②″ 关注引导卡（一行式，配色跟主题走）

单独一行写 && 口号 | 引导语 | 栏目名 | 时间档 | 底部提示，五个字段用半角 | 分隔，例如：
&& 喜欢这篇的文字 | 点亮右下角的「赞」和「推荐」\n让我知道，有人在认真读 | | 一段文字 · 一刻澄心 | 长按二维码 · 关注一字澄心
渲染成「疏排口号 + 引导语 + 浅底卡（时间档 / 白底二维码 / 底注）」，颜色随当前主题自动换，
栏目名这段默认留空：底部提示已有账号名，卡里写两遍重复（老稿里写了的仍照常渲染，想去掉就留空）。 换什么主题发都协调。卡盒尺寸与片段库里的关注卡片逐项对齐（8px 圆角、内边距 24/20/22、二维码白框 160px）， 所以两种写法、四个栏目下，关注卡大小都一样。
引导语里写 \n 强制换行；某段不想要就留空（两个连续的 ||）。
二维码自动用抽屉里保存的那张（没存则显示占位，复制前记得先存）。
和片段库里的关注卡片什么区别：片段是固定配色（夜读金 / 热搜橘 / 墨绿各一张）； 这个是主题色实时渲染，适合临时换别的主题发稿。两边可以并存，按需取用。

③ 排版体检（复制前先过一遍）

顶栏点「排版体检」，把「粘到公众号会坏」的隐患一次列出来。检查项全部来自实测踩过的坑：
错误级（必须先修，会影响发布效果）：
· 出现 display:flex 或 <table> —— 微信粘贴时会清洗，多栏会塌成一行、表格宽度被重排
· 内联样式里出现引号 —— 会提前截断 style="..."，整段结构崩坏（字体名必须用单引号）
· 二维码占位没填 / 图片没有地址 / 图片是本地路径（file:// 或盘符）
· <section> 标签不配平
建议级（可以发，但优化一下更好）：
· 有 rem / em 相对单位 —— 读者调微信字号时会跟着缩放
· 有段落超过 420 字 —— 手机一屏约 200 字，太长读者会失去耐心
· 全文超过 500 字却一个小标题都没有
· 字号过小（小于 11px）的地方偏多
· 实测行高叠字（多为自定义片段带进来的）—— 公众号 #2.3.2 的真实判定是排版后实测： 行数≥2 且平均行高 < 0.95×字号 就弹「可能文字重叠」（声明值合规也可能中招，比如片段里用了 transform / zoom 缩放）。复制时按同一算法实测并自动抬到 字号×1.3，粘过去不再弹那个确认框
· 粘过去弹了「行高叠字」但内容其实正常？—— 这是微信线上检测器的已知误报： 一行里混着加粗 / 变色片段时，老算法把「行内片段」错数成「行数」，平均行高被稀释 3~5 倍 （官方开源仓 docs 里就有这篇误报解释，算法已在 2026-09-29 v0.2.17 修复，线上编辑器尚未同步）。 2026-10-10 起工具已在导出时自动规避：给这类段落包一层不影响观感的「撑高壳」， 把老算法量到的平均行高抬回阈值以上（观感逐像素不变，正文一个字不动）—— 正常行文（短段落 + 加粗）粘过去不再弹；万一某个自定义片段还弹，点「继续插入」即可
· 文字背景用了渐变 —— 公众号检测规则 darkmode-no-gradient，粘贴时弹「文字背景尽量不要使用渐变」。 工具自带的样式已全部规避（竖线标题原先就是个渐变背景，2026-10-09 已改成实色）， 报出来的基本都是自定义 :::html 片段
· 容器 height:0 却装着文字、text-align 用了 start/end、 光标色透明、图片 opacity:0 —— 都是公众号会弹确认框的结构问题
点「复制到公众号」时会自动先体检：有错误级问题会拦下来先给你看，只有建议则不打断、直接复制。
这几条是怎么来的：微信把「内容结构检测」做成了开源仓（wechatjs/verify-article-structure-spec）， 官方规则文档 + 用真实浏览器跑的检测 CLI 都在里面。上面「渐变 / height:0 / text-align」三条是照它的规则实现的本预检； 行高叠字那条也一样 —— 复制时把稿子挂到屏幕外按官方同款算法实测，命中就地抬正（体检里的计数就是实测结果）。

④ 行距两档

常规（正文 1.95 / 段间距 18px）　紧凑（1.85 / 16px，同篇幅少滑约半屏）。
只动行距与段间距，字号、字距、字体三者完全不变，所以看起来还是同一个号的版面。
四个栏目的骨架都铺「常规」，默认观感完全一致；想收紧某一篇随时切「紧凑」。

④′ 正文字号（14–20px，滑杆旁边就是具体数字）

主题栏最右边的滑杆调的是正文（段落 / 列表）的字号，刻度就是读者手机上看到的 px， 旁边那块紫色数字牌同步显示当前值 —— 不用再猜「这一格是多大」。
默认值：夜读 / 热搜 / 带货 16px，科普 15px（科普版式本身走的是参考那篇科普号的紧字距）。
推荐怎么选：
· 16px —— 微信图文最稳的默认值，手机一屏约 200 字，长文也不累眼，建议就停在这
· 15px —— 想在一屏里多塞两行、或文章偏资讯速读时用
· 17–18px —— 老年读者偏多、金句多、段落极短的号可以考虑
· 14px 偏小、19–20px 偏大：14px 手机上看略吃力，19px 以上正文会有点像小标题， 一般只用来做短篇或强情绪的号
它是全局倍数：拖滑杆时标题、引用、图注、列表会按同一比例一起缩放， 所以版面比例永远协调，不会只有正文变大、标题不动。
字号写死 px（不用 rem / em），读者在微信里「调整字号」时，你这篇的字号不会被跟着乱缩放 —— 这也是「排版体检」反复强调的一条。

⑤ 四个栏目

版式一样、配色和标题档各自不同 —— 读者一眼知道是哪个栏目，也知道是同一个号。
夜读：米色 + 深蓝 + 金，强调下划线用金，标题章节条（刊物感）
热搜：暖橘 + 砖红，强调下划线用浅橘，标题序号（清单感、快节奏）
科普：浅绿 + 墨绿 + 黄底线，强调下划线用浅绿，标题竖线（线条化、不抢戏）
带货：玫红 + 酒红 + 金，强调下划线用浅玫粉，标题色块（整条实色底、促销味）； 骨架在 03 后面自带商品卡 + 购买引导两张卡（名称 / 卖点 / 价格、怎么下单）—— 这两张是带货专属，切到别的栏目时不会被换掉或删掉，你填的内容原样留着
四个栏目用同一套架构（引言 → 01/02/03 → 写到最后 → 点赞 → 关注卡）、 同一套组件尺寸（点赞 / 关注卡 / 重点句卡逐项对齐，见 ②′）、 同一种强调手法（下划线）、同一档行距（常规）、同一档正文字号（见 ④′）—— 差的只有配色和标题档位：配色让你认出栏目，标题档位是每个栏目那枚「标题指纹」， 所以四个栏目写起来手感一致，切过去版面尺寸不动，换的是颜色和标题的排法。
栏目切换在顶栏左侧：切过去带来的不只是配色，还有那个栏目上次写的那篇稿，四边各存一份、互不覆盖。
打开的方式：回到上次停的那个栏目 —— 写过就把那篇原样摆回来；没写过就铺好它自己的整篇架构。 四个栏目都有一套完整架构，所以打开永远不会是空白页，也不会替你跳到别的栏目去。
旧稿自动跟上新版式：老草稿里的旧尺寸卡片（大刊头 / 大关注卡 / 无描边重点句）在打开或切栏目时 自动换成本栏目新版，卡里你自己写的那句话保留。
老稿的标题档也一起换成本栏目默认档（只升一次）：分栏默认档之前写的稿， 标题还停在当年那个档，打开时自动变成本栏目那一档 —— 夜读稿本来就是这个档，看不出变化； 热搜 / 科普 / 带货稿会从章节条换成序号 / 竖线 / 色块（正文一个字不动）。 升级只做一次，之后你在顶栏自己挑的档位照常记进草稿、不会再被默认值改写； 想主动重来一遍就点编辑器上方「重铺架构」（那个会连正文一起换成空架构）。
抽屉里的片段按栏目分组，并按文章从上到下的顺序排列，照着拼即可。

⑥ 二维码（每个栏目可以不一样）

抽屉里先点哪个槽，再选图，图就存进那个槽 —— 槽位有两级：
· 通用：五个栏目共用的一张，没单独设置过的栏目都走它（带绿勾 = 这个槽自己存过图）；
· 某个栏目（夜读 / 热搜 / 科普 / 带货 / 财税）：单独存一张，切到这个栏目时优先用它， 别的栏目不受影响。哪个栏目换了号，就给它单独存一张，之后不用每篇重贴。
工具会自动压缩成 320px 小图再保存（几 KB，不影响扫码）。 编辑器里只保留一行「二维码图片放这里」短占位，预览和复制到公众号时才替换成真图 —— 源码里不会出现长串 base64 字符。 正文里已经填过真图的旧稿，点「把正文里的二维码换成「X」的」一次就能刷成当前栏目该用的那张。 旧版存过大图的，点「压缩瘦身」一键重压。

⑦ 配置备份

二维码、主题设置、自定义片段、四个栏目各自的草稿都存在浏览器本地。清缓存或换电脑前， 抽屉底部点「导出配置」存一个 JSON；换环境点「导入配置」完整还原。

⑧ 图片相关

⑨ 放进自己写好的 HTML 组件

点顶栏「HTML 片段」：内置刊头、点赞引导、关注卡片等，点「插入」进正文； 自己的 HTML 也能存进「我的片段」。
也可直接粘：HTML 上下各加一行 :::html 和 :::。 围栏里的内容原样输出，主题和正文字号滑杆都不会改动它。
